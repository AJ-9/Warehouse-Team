# 🚂 Развертывание на Railway.app

## Почему Railway?

Railway - лучший выбор для вашего проекта:
- ✅ **$5 бесплатных кредитов** каждый месяц
- ✅ **Без спящего режима** (в отличие от Heroku)
- ✅ **Автоматическое развертывание** из GitHub
- ✅ **Встроенная PostgreSQL** база данных
- ✅ **HTTPS** из коробки
- ✅ **Глобальный CDN** для быстрого доступа

## 🚀 Пошаговое развертывание

### Шаг 1: Создайте GitHub репозиторий

1. Перейдите на [GitHub.com](https://github.com)
2. Нажмите "New repository"
3. Назовите репозиторий: `dispatcher-system`
4. Сделайте его **публичным** (для бесплатного Railway)
5. Загрузите все файлы проекта

### Шаг 2: Создайте аккаунт Railway

1. Перейдите на [Railway.app](https://railway.app)
2. Нажмите "Login" → "Login with GitHub"
3. Авторизуйте Railway доступ к вашему GitHub

### Шаг 3: Создайте проект

1. Нажмите "New Project"
2. Выберите "Deploy from GitHub repo"
3. Найдите ваш репозиторий `dispatcher-system`
4. Нажмите "Deploy Now"

### Шаг 4: Добавьте базу данных

1. В проекте нажмите "+ New"
2. Выберите "Database" → "PostgreSQL"
3. Railway автоматически создаст базу данных

### Шаг 5: Настройте переменные окружения

В настройках проекта добавьте:

```
SECRET_KEY=your-very-secure-secret-key-here-12345
ADMIN_USERNAME=admin
ADMIN_PASSWORD=Dispatcher2024!
FLASK_ENV=production
```

### Шаг 6: Получите URL

1. Railway автоматически развернет приложение
2. Скопируйте URL из раздела "Domains"
3. Ваше приложение будет доступно по адресу: `https://your-app-name.railway.app`
