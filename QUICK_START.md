# 🚀 Быстрый старт - Диспетчерская система

## 🎯 Что у вас есть

Полноценная диспетчерская система для отслеживания транспортных средств с:
- ✅ Веб-интерфейсом
- ✅ Безопасным входом
- ✅ Готовностью к развертыванию в облаке
- ✅ Экспортом в Excel
- ✅ Фильтрацией и поиском

## 🏃‍♂️ Быстрый локальный запуск

### Вариант 1: Автоматический запуск
```bash
python test_local.py
```
Скрипт автоматически:
- Проверит Python
- Установит зависимости
- Создаст файл .env
- Запустит приложение

**Данные для входа:** `admin` / `admin123`

### Вариант 2: Ручной запуск
```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Создайте файл .env
cp .env.example .env

# 3. Запустите приложение
python dispatcher_app.py
```

## 🌐 Развертывание в облаке

### Heroku (Рекомендуется)
```bash
# 1. Установите Heroku CLI и войдите
heroku login

# 2. Создайте приложение
heroku create your-dispatcher-app

# 3. Добавьте базу данных
heroku addons:create heroku-postgresql:mini

# 4. Установите переменные
heroku config:set SECRET_KEY=$(python -c "import secrets; print(secrets.token_hex(16))")
heroku config:set ADMIN_USERNAME=admin
heroku config:set ADMIN_PASSWORD=your-secure-password
heroku config:set FLASK_ENV=production

# 5. Разверните
git init
git add .
git commit -m "Initial commit"
git push heroku main

# 6. Откройте
heroku open
```

### Railway (Альтернатива)
1. Создайте аккаунт на [Railway.app](https://railway.app)
2. Подключите GitHub репозиторий
3. Добавьте переменные окружения:
   - `SECRET_KEY`: случайная строка
   - `ADMIN_USERNAME`: admin
   - `ADMIN_PASSWORD`: ваш пароль
   - `FLASK_ENV`: production

## 📱 Доступ к системе

После развертывания система будет доступна по URL:
- **Локально**: http://localhost:5000
- **Heroku**: https://your-app-name.herokuapp.com
- **Railway**: https://your-app-name.railway.app

## 🔐 Безопасность

- Все страницы защищены аутентификацией
- Пароли настраиваются через переменные окружения
- Рекомендуется использовать сложные пароли в продакшене

## 📊 Функции системы

1. **Добавление записей** - полная информация о ТС
2. **Редактирование** - изменение любых данных
3. **Фильтрация** - поиск по статусу, локации, водителю
4. **Экспорт Excel** - выгрузка всех данных
5. **Статусы** - отслеживание состояния ТС
6. **Время** - точное время прибытия/убытия

## 🆘 Если что-то не работает

1. **Проверьте Python версию** (требуется 3.7+)
2. **Установите зависимости**: `pip install -r requirements.txt`
3. **Проверьте файл .env** - должен содержать все переменные
4. **Посмотрите логи** - в консоли или через `heroku logs --tail`
