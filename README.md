# 🚛 Система управления транспортом в реальном времени

Полноценная система управления транспортными средствами с поддержкой работы в реальном времени, доступная бесплатно без VPN в России.

## ✨ Возможности

- 📱 **Адаптивный дизайн** - работает на смартфонах и компьютерах
- 🔄 **Синхронизация в реальном времени** - изменения видны всем пользователям
- 💾 **Офлайн поддержка** - работает без интернета с локальным сохранением
- 🔍 **Поиск и сортировка** по всем полям
- 📊 **Статистика** в реальном времени
- 📤 **Экспорт данных** в CSV
- 🆓 **Полностью бесплатно** - использует только бесплатные сервисы

## 🚀 Быстрый старт

### Вариант 1: GitHub Pages (Рекомендуется)

1. **Создайте репозиторий на GitHub:**
   - Перейдите на [github.com](https://github.com)
   - Нажмите "New repository"
   - Назовите репозиторий (например: `transport-system`)
   - Сделайте репозиторий **публичным**

2. **Загрузите файл:**
   - Скачайте файл `transport_realtime.html`
   - Переименуйте его в `index.html`
   - Загрузите в корень репозитория

3. **Включите GitHub Pages:**
   - Перейдите в Settings → Pages
   - Source: Deploy from a branch
   - Branch: main
   - Нажмите Save

4. **Получите ссылку:**
   - Ваш сайт будет доступен по адресу: `https://ваш-username.github.io/transport-system/`

### Вариант 2: Netlify (Альтернатива)

1. Перейдите на [netlify.com](https://netlify.com)
2. Перетащите файл `transport_realtime.html` в область загрузки
3. Получите мгновенную ссылку

## 🔧 Настройка синхронизации

1. **Откройте вашу таблицу** в браузере
2. **Создайте репозиторий** для данных (например: `transport-data`)
3. **Введите имя репозитория** в формате `username/repository-name`
4. **Нажмите "Подключиться"**

Теперь все изменения будут автоматически синхронизироваться между устройствами!

## 🔄 Как работает синхронизация

1. **Локальное сохранение** - все данные сохраняются в браузере
2. **GitHub API** - используется для хранения данных в облаке
3. **Автосинхронизация** - каждые 30 секунд проверяются обновления
4. **Офлайн режим** - работает без интернета, синхронизируется при подключении

## 🆘 Решение проблем

### Проблема: Не работает синхронизация
**Решение:** 
- Проверьте правильность имени репозитория
- Убедитесь, что репозиторий публичный
- Проверьте подключение к интернету

### Проблема: Данные не сохраняются
**Решение:**
- Проверьте настройки браузера (разрешить localStorage)
- Попробуйте другой браузер
- Очистите кэш браузера

### Проблема: Медленная работа
**Решение:**
- Закройте другие вкладки браузера
- Проверьте скорость интернета
- Используйте современный браузер
