# Диспетчерская система

Веб-приложение для управления транспортными средствами и отслеживания их статусов.

## Возможности

- ✅ Добавление, редактирование и удаление записей о транспортных средствах
- ✅ Отслеживание статусов: на складе в очереди, покинул склад, ПАД-4, в пути, за забором в очереди, КПП-6
- ✅ Фильтрация и поиск по различным полям
- ✅ Экспорт данных в Excel
- ✅ Современный веб-интерфейс с Bootstrap
- ✅ Адаптивный дизайн для мобильных устройств

## Поля данных

1. **Локация** (место выгрузки) - обязательное поле
2. **Номер транспортного средства** - обязательное поле
3. **Очередность** - числовое поле
4. **Статус** - выпадающий список с предустановленными значениями
5. **ФИО водителя** - обязательное поле
6. **Телефон** - контактный номер
7. **Поставщик** - название поставщика
8. **Титул** - дополнительная информация
9. **Дата прибытия** - календарное поле
10. **Время прибытия** - поле времени (часы:минуты)
11. **Дата убытия** - календарное поле
12. **Время убытия** - поле времени (часы:минуты)
13. **Номер ТН** - номер товарной накладной
14. **Комментарии** - текстовое поле для дополнительной информации

## Установка и запуск

### Требования
- Python 3.7+
- pip

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск приложения
```bash
python dispatcher_app.py
```

Приложение будет доступно по адресу: http://localhost:5000

## Использование

1. **Главная страница** - просмотр всех записей с возможностью фильтрации
2. **Добавить запись** - создание новой записи о транспортном средстве
3. **Редактировать** - изменение существующих записей
4. **Удалить** - удаление записей с подтверждением
5. **Экспорт Excel** - выгрузка всех данных в Excel файл

## Фильтрация

На главной странице доступны фильтры по:
- Статусу (выпадающий список)
- Локации (текстовый поиск)
- Номеру транспортного средства (текстовый поиск)
- ФИО водителя (текстовый поиск)

## База данных

Приложение использует SQLite базу данных (`dispatcher.db`), которая создается автоматически при первом запуске.
